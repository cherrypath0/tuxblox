# TuxBlox Documentation

This is the official documentation for TuxBlox, the launcher and compatibility layer for running Roblox on Linux.

This directory is updated before [tuxblox.net/docs](https://tuxblox.net/docs), and the website is synced from it regularly. If the two ever disagree, this one is right.

## Something missing or wrong?

Documentation bugs are bugs. Open an issue, or tell us in [Discord](https://tuxblox.net/discord).

## Editing these pages

`docs-info.json` decides the order and the titles shown in the sidebar on the website. Adding a page means adding it there too, or it will not appear.
