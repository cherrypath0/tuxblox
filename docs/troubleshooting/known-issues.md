# Known Issues

This page lists problems we already know about. If you run into one of these, you do not need to report it, we are already aware and working on it.

If your problem is not listed here, see [Reporting Bugs](reporting-bugs.md).

## Roblox Player does not start yet

Roblox's anti-cheat system currently blocks Roblox Player from starting under Wine-based compatibility layers, including TuxBlox. Roblox Studio is not affected by this and works normally.

Getting Player working is one of our biggest current priorities.

## Some visual glitches while resizing Roblox Studio

You may notice occasional rendering glitches while resizing a Roblox Studio window. This does not affect Roblox Studio itself and only affects how it looks briefly while resizing.

We are working on a fix.
