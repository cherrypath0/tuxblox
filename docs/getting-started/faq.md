# Frequently Asked Questions

## Is TuxBlox free?

Yes. TuxBlox is completely free and open source.

## What can TuxBlox do?

TuxBlox includes, among other things:

- A compatibility layer tuned specifically for Roblox, for better performance
- A FastFlag editor built into the launcher
- Automatic installs and updates
- A beginner friendly interface

See [How TuxBlox Works](how-it-works.md) for more on what is happening behind the scenes.

## Does Roblox Studio work?

Yes, Roblox Studio runs under TuxBlox.

## Does Roblox Player work?

Not yet. Roblox's anti-cheat system currently blocks Roblox Player from starting under Wine-based compatibility layers, including TuxBlox. This is one of our main focuses, and support is actively being worked on. Check [Known Issues](../troubleshooting/known-issues.md) for the latest status.

## Can I use TuxBlox's compatibility layer for anything other than Roblox?

TuxBlox's compatibility layer is built and tuned specifically for Roblox, so we cannot guarantee it will work well for other Windows programs. That said, we do offer it as a separate download on our [releases page](https://tuxblox.net/releases) if you would like to try it for something else.

## Where can I get help?

Join our [Discord server](https://tuxblox.net/discord). It is also the best place to get support, follow development updates, and chat with other users.
