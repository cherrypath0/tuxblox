# Welcome to TuxBlox

TuxBlox lets you run Roblox Studio (and, soon, Roblox Player) on Linux. It uses a compatibility layer built specifically for Roblox, so you do not need Windows, a virtual machine, or WSL.

This documentation will help you install TuxBlox, understand how it works, and fix common problems. If something is not covered here, ask in our [Discord server](https://tuxblox.net/discord).

## What TuxBlox gives you

- **Easy setup.** The installer handles installation and updates for you.
- **Good performance.** TuxBlox's compatibility layer is tuned specifically for Roblox, not for general Windows programs.
- **Simple controls.** Change settings from the launcher instead of editing files by hand.
- **Free and open source.** Anyone can read the code or contribute to it.
