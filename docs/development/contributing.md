# Contributing

Thanks for wanting to help out with TuxBlox! The full contributing guide, including code style, licensing rules, and what kinds of contributions we do and do not accept, lives in [`CONTRIBUTING.md`](https://github.com/cherrypath0/tuxblox/blob/main/CONTRIBUTING.md) at the root of the repository.

Before contributing, it also helps to read:

- [Building From Source](building-from-source.md), to get TuxBlox building locally
- [Repository Structure](repository-structure.md), to understand how the project is laid out

If anything is unclear, ask in our [Discord server](https://tuxblox.net/discord).
